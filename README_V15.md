# PlexAI Verify v15.0 — Autonome

Cette version ajoute une gestion des collections et une wishlist qui fonctionnent sans Radarr.

## Nouveautés

- comparaison locale avec les films indexés ;
- détection des titres manquants ;
- priorités de 1 à 5 étoiles ;
- stockage dans SQLite ;
- export CSV et JSON ;
- catalogue local personnalisable ;
- Radarr reste optionnel.

## Démarrage

1. Lance `py main.py`.
2. Scanne la bibliothèque.
3. Ouvre **Wishlist**.
4. Clique sur **Analyser mes collections**.
5. Complète `collection_catalog.json` avec tes propres sagas.

Le catalogue inclus contient seulement Alien et Mission: Impossible comme exemples fonctionnels. Les résultats dépendent des films indexés et du contenu du catalogue.
